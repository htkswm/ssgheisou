# サガスカ周年並走会 — 記録サイト

『サガ スカーレット グレイス 緋色の野望』の発売日（8月2日）に、みんなでサガスカを周回する
ゆる～い企画 **周回並走会（#サガスカ〇周年並走会）** の案内・ルール・記録サイトです。

## サイトを見る

🔗 **公開サイト**: https://htkswm.github.io/ssgheisou/

ページ構成:

- **ホーム** … 最新開催のお知らせ・企画の概要
- **ルール** … 計測区間・ポストのしかた・Q&A
- **記録（8周年 2026 / 7周年 2025）** … 各回の周回テーマ・記録・ポスト／アーカイブへのリンク
- **Link** … 公式サイト・配信ガイドライン・過去の案内・素材提供元

## 記録データ

各回の記録は `assets/records-YYYY.json` に構造化して保存しています。
HTML のカード部分はこの JSON から生成しています。
